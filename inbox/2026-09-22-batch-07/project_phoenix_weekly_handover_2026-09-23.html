Discussion prompts

Questions worth asking Colin

Use these as prompts—not a rigid questionnaire. Open only the group relevant to what you are screen-sharing.

System landscape & architecture
  • What are all active applications/services you currently support for Sensatia beyond StockWizz?
  • Which repository and branch is the actual production source for each application?
  • Are there personal forks, local-only scripts, or tools production still depends on?
  • What cron jobs, workers, queues or scheduled processes are currently active?
  • Which components are legacy-but-used versus genuinely deprecated?
  • Can we trace one real StockWizz flow end-to-end: frontend → API → MongoDB → job/integration?
Deployment, release & rollback
  • For the 22 Sep release, what exact steps did you perform from approved change to production?
  • Which repo/branch and build/deploy mechanism is used?
  • What is different between local, Sandbox/SB and Production?
  • Where are environment variables managed and who owns them?
  • Which Better Stack queries / health checks do you normally use after deploy?
  • What jobs/services need restart or verification after a release?
  • What is the actual rollback procedure if code is bad—and what changes if data has already been mutated?
  • Which safe change can I deploy next under your review?
Jubelio integration
  • Where are the StockWizz → Jubelio adjustment code and Jubelio → StockWizz webhook handlers?
  • What identifier prevents duplicate transaction / stock deduction?
  • Which Jubelio statuses are accepted in Production versus Sandbox?
  • What happens on webhook retry, duplicate delivery, partial failure or timeout?
  • How should cancel, partial cancel, return and refund affect StockWizz stock?
  • How does the reconciliation route work, and should it run automatically each day?
  • What is the actual Bali/Jakarta fulfillment-assignment rule today?
  • Who owns Jubelio/API credentials and what is the recovery/rotation path?
Accounting / Putu Mei
  • Where is the safest backend enforcement point for credit validation before Quote/Order conversion?
  • Which fields/collections are source of truth for payment term, due date, outstanding balance and partial payment?
  • Which existing email provider/service/queue should be reused for Invoice and Tax Invoice delivery?
  • What cron/job framework should run the H+1 Tax Invoice delivery?
  • How are uploaded files stored/versioned, and how should “updated after sent” be detected?
  • Which small implementation should I complete first so you can review it before Sandbox?
Access & ownership
  • Which critical accounts still use your personal email, phone, MFA or recovery method?
  • Which accounts already have Sensatia-controlled admin/recovery access?
  • What access do I need now to troubleshoot and deploy to Sandbox independently?
  • Which access should involve Agus because it belongs to infrastructure/recovery rather than application development?
