Strong evidence

Dated test result, deployment/change record, code/config state, verified owner confirmation, recovery test, approved decision or signed/recorded acceptance.

Supporting evidence

Architecture docs, runbooks, Jira/Confluence analysis, screenshots, repository docs and meeting/KT records that explain context.

Not evidence by itself

Blank template, unverified assumption, undocumented verbal statement, expired screenshot, or a link that does not prove the criterion.

Evidence chain recommendation

Requirement → Asset ID / Work ID → Jira action → Confluence/repo procedure → test/change/recovery evidence → validator/date → status → next review.
