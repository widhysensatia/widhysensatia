Transition in Progress

Core principle

If critical knowledge is not documented, it should not be considered transferred.

Completion rule

Capability must be demonstrated and acceptance recorded. February is a target review point, not an automatic pass date.

Foundation

DG-001 mendefinisikan DTAR sebagai authoritative inventory untuk material digital systems, software, infrastructure, services, repositories, databases, websites, integrations, credentials and cloud platforms.

Five readiness criteria

Untuk critical assets, dashboard DTAR menilai company controlled, documented, backup confirmed, recovery tested dan transferred to Widi.

Dependency visibility

Colin dependency, company-controlled recovery, personal account dependency, evidence references dan owner/date harus terlihat; bukan disembunyikan.
