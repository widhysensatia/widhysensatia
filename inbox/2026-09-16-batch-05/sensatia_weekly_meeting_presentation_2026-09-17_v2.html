Integration direction

Order operasional masuk cepat. Finance menyusul setelah transaksi matang.

Jubelio eventOrder create, update, cancellation, dan external status.
Scheduled reconciliationSafety net untuk event gagal, terlambat, atau tidak lengkap.
API
idempotent
StockWizz orderUpsert SKU, quantity, warehouse, external ID, dan status kritis.
Finance enrichmentFee, voucher, tax, dan settlement ditarik async setelah final.
webhook fast pathqueue / workerexternal unique keycancel = critical event

Technical guardrails

  • Webhook receiver hanya verify, persist event, deduplicate, lalu respond cepat.
  • Gunakan source + external_order_id sebagai integration key jika semantics _sale_id belum terverifikasi.
  • Pisahkan external_order_status dan internal fulfillment_status.
  • Cancellation sebelum pack harus release reservation atau block fulfillment.
  • Cancellation setelah pack masuk exception flow, bukan blind overwrite.
  • Endpoint, webhook events, pagination, rate limits, dan finance fields wajib diverifikasi dari dokumentasi Jubelio aktif.
Recommended sequence: contract discovery → operational MVP → cancellation → reconciliation → finance enrichment
