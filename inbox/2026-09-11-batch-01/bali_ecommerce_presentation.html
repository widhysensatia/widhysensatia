01 · Why Now

Tiga problem berbeda terlihat seperti satu masalah “stock”.

Kita perlu memisahkan integration bug, physical capacity, dan routing complexity sebelum membuat perubahan besar.

Integration

Absolute sync salah

Production test membuktikan API ter-trigger, tetapi Jubelio di-overwrite dengan final StockWizz balance.

Capacity

SECM sangat terbatas

Stockroom Padang Galak dan Bali E-Commerce berbagi ruang; SECM hanya mendapat sekitar 2 baris rak kecil.

Routing

Terlalu banyak sync points

Semua marketplace dual-WH menambah stock allocation, warehouse routing, reconciliation, dan exception handling.

Prinsip deck ini: jangan menyelesaikan OOS dengan satu asumsi. Kita benahi source-of-truth terlebih dahulu, lalu menyederhanakan network berdasarkan demand dan capacity.

04 · Fix Before Scale

Movement-first, location-aware, lalu reconciliation setelah dua arah stabil.

Saldo StockWizz dan Jubelio tidak boleh dipaksa sama selama transaction return path belum real-time dan intentional allocation masih berlaku.

P0

Inbound delta

Refill → generate delta → apply allocation % → Jubelio Stock Adjustment. Idempotent, logged, retry-safe.

P1/P2

Transaction return

Marketplace sale → Jubelio transaction → resolve fulfillment warehouse → deduct StockWizz.

Later

Reconciliation

Bandingkan expected movement vs actual movement; jangan sekadar equalize final balances.

Refill +10StockWizz +10
Allocation 80%Jubelio +8
Marketplace sale -3Jubelio transaction
Return pathStockWizz -3 pada location benar

07 · Website Routing Proposal

Website `/id` → Jakarta. Regional / international → Bali.

Ini memisahkan “siapa yang mengendalikan supply” dari “siapa yang mengerjakan fulfillment”. Bali tetap strategic supply anchor.

JECM
sensatia.com/id → Jakarta

Domestic fulfillment, capacity lebih besar, manpower lebih memungkinkan, destination demand banyak menuju Jawa.

SECM
Regional / international → Bali

Tetap di Bali karena flow regional membutuhkan surat jalan dan masih workable secara operasional.

Benefit

SECM space relief

Domestic web stock/workload tidak lagi bersaing penuh dengan marketplace dan regional web di rak kecil.

Benefit

Domestic execution

Jakarta lebih dekat ke mayoritas domestic destination dan lebih mendukung instant logistics.

Validate

Cost & SLA

Expected improvement harus dibuktikan dengan actual ongkir, lead time, SLA dan cancellation saat pilot.

11 · Risk Register

Doable? Ya. Tetapi simplifikasi routing memindahkan beberapa risiko ke Jakarta.

Tujuannya bukan menghilangkan kompleksitas; tujuannya memusatkan kompleksitas di tempat yang lebih mampu mengelolanya.

Jakarta single pointHigh

Non-Shopee bisa terdampak bersamaan jika JECM bermasalah.

Replenishment lead timeHigh

Supply source di Bali; Jakarta perlu MIN/TARGET & safety stock.

Wrong WH deductionHigh

Order harus deduct StockWizz pada fulfillment warehouse yang benar.

Shopee dual-nodeMedium

Complexity tetap ada, tetapi justified oleh 77–80% share order.

Return / cancelMedium

Restock harus kembali ke ledger/location yang benar.

Campaign surgeMedium

Jakarta demand akan naik; capacity plan harus melihat campaign uplift.

Assessment

Operational feasibility · 8/10

Network logic dan demand distribution mendukung Jakarta-first.

Assessment

Technical readiness · 6/10

Masih conditional sampai location mapping, outbound deduction, exception handling dan reconciliation siap.

15 · Recommendation

Target yang disarankan: simpler routing, stronger stock movement, clearer ownership.

1

Jubelio first

Fix delta-based inbound dan outbound transaction loop sebelum auto-reconciliation.

2

Website `/id` → Jakarta

Domestic execution pindah ke JECM; regional/international tetap Bali.

3

Selective marketplace routing

Shopee dual-node; non-Shopee Jakarta-first, dengan fallback policy eksplisit.

Bali tidak kehilangan kontrol. Factory dan supply anchor tetap di Bali. Yang dipindahkan adalah execution workload yang lebih cocok ditangani Jakarta.
Open decisions

Masih perlu diputuskan sebelum scale

Fallback `/id`, actual replenishment lead time, safety stock JECM, rounding allocation, return/cancel path.

Next
