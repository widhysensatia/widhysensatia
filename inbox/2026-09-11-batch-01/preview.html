03 · Jubelio Update

CSV sudah memberikan quick win. Sekarang API automation harus menyelesaikan technical sync dan master-data alignment.

Current · Delta CSV

StockWizz refill → export delta CSV → upload ke Jubelio.

Sudah digunakan dan mengurangi input manual.

Tetapi kadang terdapat SKU yang gagal match / tidak ditemukan.

SKU tersebut akhirnya ditangani manual oleh user.

Working SKU mismatch Manual recovery

Target · Automatic API

StockWizz event → exact SKU lookup → resolve Jubelio item_id → Stock Adjustment API.

Matched item tetap sync.

Unmatched item skip + report.

Tidak menggunakan fuzzy product-name matching dan tidak auto-create product.

How we arrived here
Step 1
Goal awal saya sederhana

Automate flow CSV yang sudah terbukti. Refill StockWizz langsung mengupdate Jubelio.

Step 2
Product identity menjadi blocker

StockWizz dan Jubelio mempunyai internal ID berbeda. Jubelio Stock Adjustment API membutuhkan internal item_id. Shared business identifier yang seharusnya dipakai adalah exact SKU/item code.

Step 3
Awalnya ada perbedaan pandangan dengan Colin

Colin ingin menghindari vendor-specific mapping dan berharap shared SKU cukup digunakan langsung. Setelah kita konfirmasi ke Jubelio bahwa Stock Adjustment membutuhkan item_id, resolution/mapping layer memang diperlukan.

Step 4
Current direction

Exact SKU → lookup Jubelio → resolve item_id → stock adjustment. Jadi SKU tetap menjadi business identity StockWizz, sedangkan Jubelio-specific ID tetap berada di integration layer.

Step 5
Failure handling

Matched product → sync. Unmatched product → skip + report. StockWizz transaction tetap tersimpan. Tidak auto-create Jubelio product.
